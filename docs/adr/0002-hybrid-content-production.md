# 内容生产：自动结构演示 + 手作讲解

场景内容采取**混合生产**：机器 / 多方块的**搭建顺序、控制器与仓口高亮、成型演示、模块安装演示**由引擎从 GT 结构数据（分层结构 + 模块位区域）**自动生成**；**概念课、使用流程、原理讲解**必须由作者精作。自动产物视为**可重生成的构建产物**，手作以**场景粒度**覆盖 / 扩展。

**Status**: accepted

**Considered Options**:

- **混合（选定）**：兼顾"覆盖全部"的广度与教学质量的深度。
- 全自动：覆盖面最大，但流程 / 原理无法从结构数据推导，教学叙事弱、质量参差。
- 全手作：质量最高，但覆盖全部 GT 内容在工期上不可行。

**Consequences**:

- 自动生成器需要**结构角色分类**（控制器 / 仓口 / 总线 / 线缆 / 外壳…）与**超大机器单元格预算**策略。
- 自动产物携带 `generatorVersion`，GT fork 升级后可重生成并 diff。
- 手作与自动之间**只允许场景级合并**，避免数据格式退化为编程语言。
